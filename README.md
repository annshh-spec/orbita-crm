# Орбита — CRM-система: как запустить на своём домене

Это готовый сайт CRM. Вход только по логину и паролю. У директора полный доступ, сотрудники видят только разрешённые разделы. Все данные хранятся на вашем сервере в одном файле: `data/crm.db`.

## Что понадобится

1. **Сервер (VPS)** у российского хостинга, например Timeweb Cloud, Beget, Selectel или REG.RU. Подойдёт самый простой тариф: 1 ядро и 1 ГБ памяти. Операционная система — Ubuntu 24.04. Все эти хостинги принимают российские карты.
2. **Домен**, например `crm.вашакомпания.ru`. В настройках домена создайте A-запись, которая указывает на IP-адрес сервера.
3. **Почта для отправки приглашений**, например ящик на Яндекс 360 или в Яндекс Почте. В Яндекс ID создайте «пароль приложения» для почты: именно он указывается в настройках CRM.

## Установка (один раз)

Подключитесь к серверу по SSH. Команду для подключения хостинг показывает в личном кабинете. Затем выполните по очереди:

```bash
# 1. Установить Node.js 22, nginx и certbot
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt-get install -y nodejs nginx certbot python3-certbot-nginx unzip

# 2. Загрузить архив crm-app.zip на сервер (через панель хостинга или scp) и распаковать
sudo mkdir -p /opt/crm && sudo unzip crm-app.zip -d /opt/crm && cd /opt/crm/crm-app
# (сторонние пакеты не нужны: npm install запускать не обязательно)

# 3. Создать файл настроек
sudo cp .env.example .env
sudo nano .env
```

В файле `.env` укажите:

- `COMPANY_NAME` — название компании;
- `APP_URL` — адрес вашего домена, начиная с `https://`;
- `ADMIN_NAME`, `ADMIN_EMAIL`, `ADMIN_PASSWORD` — ваши имя, логин и пароль директора. Пароль должен быть не короче 8 символов и содержать буквы и цифры;
- `SMTP_...` — настройки почты для приглашений.

Чтобы сохранить файл в редакторе nano, нажмите Ctrl+O, затем Enter, затем Ctrl+X.

```bash
# 4. Запустить CRM как службу (будет перезапускаться сама)
sudo tee /etc/systemd/system/crm.service >/dev/null <<'EOF'
[Unit]
Description=CRM
After=network.target
[Service]
WorkingDirectory=/opt/crm/crm-app
ExecStart=/usr/bin/node --no-warnings server.js
Restart=always
User=root
[Install]
WantedBy=multi-user.target
EOF
sudo systemctl daemon-reload && sudo systemctl enable --now crm

# 5. Подключить домен (замените crm.example.ru на свой)
sudo tee /etc/nginx/sites-available/crm >/dev/null <<'EOF'
server {
  server_name crm.example.ru;
  location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For $remote_addr;
    proxy_set_header X-Forwarded-Proto $scheme;
  }
}
EOF
sudo ln -sf /etc/nginx/sites-available/crm /etc/nginx/sites-enabled/crm && sudo nginx -t && sudo systemctl reload nginx

# 6. Бесплатный SSL-сертификат (замок https)
sudo certbot --nginx -d crm.example.ru
```

После этого откройте свой домен в браузере и войдите с `ADMIN_EMAIL` и `ADMIN_PASSWORD` из `.env`. Вы директор своей компании и владелец Орбиты: вам доступен раздел «Заявки», где вы одобряете новые компании.

**Важно:** после первого входа удалите строку `ADMIN_PASSWORD` из `.env` или смените пароль в разделе «Настройки», чтобы он не хранился в файле.

## Если забыли пароль директора

```bash
cd /opt/crm/crm-app && sudo node --no-warnings server.js reset-admin ваш@email.ru НовыйПароль2026 && sudo systemctl restart crm
```

## Резервная копия

Все данные лежат в папке `/opt/crm/crm-app/data`. Регулярно копируйте её, например включите автоматические бэкапы сервера в панели хостинга.

## Регистрация компаний

- На странице входа есть кнопка «Зарегистрироваться». Компания заполняет название, ИНН (10 или 12 цифр), имя, телефон и email, а на втором шаге прикрепляет документы: PDF, JPG, PNG или DOC, до 5 файлов по 10 МБ.
- После отправки компания видит сообщение «Заявка отправлена, менеджер свяжется с вами». Заявка появляется в разделе «Заявки» у владельца Орбиты (это директор из `ADMIN_EMAIL` и адреса из `PLATFORM_ADMINS`). Если почта настроена, на эти адреса приходит письмо о новой заявке.
- При регистрации пароль не вводится. В разделе «Заявки» вы открываете документы и, когда документы проверены и оплата получена, нажимаете «Подключить». Орбита создаёт компанию, придумывает пароль и отправляет логин и пароль директору на почту. Если почта не настроена, пароль показывается вам на экране, чтобы передать его вручную. Директор может сменить пароль в «Настройках».
- Если на сервере ещё нет ни одного пользователя, самая первая регистрация одобряется сразу, и этот человек становится владельцем Орбиты.
- Документы хранятся в папке `data/uploads`.
- У каждой компании свои клиенты, сделки, этапы, задачи, финансы и сотрудники. Другие компании их не видят.
- Сотрудники не регистрируются сами: их приглашает директор своей компании.
- Чтобы закрыть регистрацию новых компаний, поставьте `ALLOW_REGISTRATION=0` в `.env` и перезапустите CRM.

## Тарифы

- Третий шаг регистрации — выбор тарифа: 1 месяц — 2 990 руб., 6 месяцев — 16 740 руб. (2 790 руб. в месяц), 12 месяцев — 28 680 руб. (2 390 руб. в месяц).
- Онлайн-оплаты на сайте нет: после отправки заявки менеджер связывается с клиентом и проводит оплату сам. Выбранный тариф и сумма видны в разделе «Заявки».
- Цены меняются в двух местах: `PLANS` в `server.js` и `PLANS` в `public/app.js`, а также в тексте оферты в `public/legal.js`.

## Юридические документы

Тексты согласия на обработку персональных данных, политики конфиденциальности и оферты лежат в файле `public/legal.js`. Это шаблоны: замените всё в [квадратных скобках] на свои реквизиты и покажите тексты юристу перед запуском.

## Товары и услуги

- В меню есть раздел «Товары»: каталог того, что вы продаёте. У каждой позиции есть название, тип (товар или услуга), единица, цена, артикул и описание.
- В карточке сделки есть блок «Товары и услуги». Кнопка «добавить» открывает каталог с поиском: отметьте нужные позиции и количество. Вписывать название вручную не нужно.
- Сумма сделки считается по товарам автоматически: цена × количество. Количество можно поменять прямо в карточке.
- Цены видят только те, кому разрешено видеть суммы. Каталог по умолчанию видят все, кто видит сделки, а добавлять и менять товары может директор или сотрудник с правом «Товары и услуги → Добавлять / Изменять».

## Карточка сделки: свои поля и оплата

- В карточке сделки можно добавлять свои разделы (кнопка «Добавить раздел»), например «Информация о заказе». В разделе есть ссылки «Создать поле», «Выбрать поле» и «Удалить раздел». Типы полей: строка, число, дата, список с вариантами и «да / нет». Разделы и поля общие для всех сделок компании, а значения заполняются в каждой сделке своё: нажмите «изменить» у раздела.
- Настраивать разделы и поля может директор и сотрудники с правом «Этапы сделок → Изменять». Заполнять значения может тот, у кого есть право «Сделки → Изменять».
- К делу, комментарию и задаче в сделке можно прикрепить файлы: фото, скриншоты, PDF, Word, Excel, презентации, архивы (до 10 файлов, каждый до 15 МБ). Скриншот вставляется в комментарий сочетанием Ctrl+V, файлы можно перетащить мышкой. Фото открываются в истории сделки, документы скачиваются. Файлы хранятся в папке `data/uploads/deals`.
- Кнопка «Принять оплату» рядом с суммой сделки записывает оплату в «Финансы» как доход и в историю сделки. В блоке «Оплата» видно, сколько оплачено и сколько осталось. Кнопка видна тем, кто видит суммы и может добавлять записи в «Финансы».

## База знаний

- В базе знаний есть подразделы. Сразу созданы «Регламенты», «Продукт» и «Скрипты». Кнопкой «Подраздел» можно добавить свои, а через «⋯» на плитке подраздела — переименовать его, поменять порядок или удалить. При удалении статьи не пропадают, а переходят в подраздел, который вы выберете. Последний подраздел удалить нельзя: у каждой статьи всегда есть подраздел.
- Внутри открытого подраздела кнопка «Добавить» сразу создаёт статью в нём.
- Статью можно написать самому или загрузить документ (Word .docx, PDF, TXT, ODT, до 20 МБ). Текст из документа сам появится в статье вместе с заголовками, списками, таблицами и выделением, а сам файл прикрепится к статье. Из сканов (PDF-картинок) и старого формата .doc текст не извлекается: файл просто прикрепляется.
- В редакторе есть оформление: стиль абзаца (обычный текст, заголовки 1–3), шрифт, размер, жирный, курсив, подчёркнутый, зачёркнутый, ПРОПИСНЫЕ и строчные, цвет текста и выделения, списки, выравнивание.
- У каждой статьи есть кнопка «Скачать Word»: она собирает документ .docx с текстом и оформлением статьи. Если к статье прикреплён файл, его тоже можно скачать.
- Файлы статей хранятся в папке `data/uploads/kb`.

## Почта сотрудников

- В меню есть раздел «Почта». Каждый сотрудник один раз подключает свой рабочий ящик: вводит адрес и пароль приложения. Для Яндекса, Mail.ru, Рамблера и Gmail серверы подставляются сами, для корпоративной почты их можно указать вручную.
- Пароль приложения создаётся в настройках почтового сервиса. В Яндексе: Яндекс ID → «Безопасность» → «Пароли приложений» → «Почта», а в настройках Почты в разделе «Почтовые программы» нужно включить доступ по IMAP. В Mail.ru: настройки → «Безопасность» → «Пароли для внешних приложений».
- В Орбите видны папки ящика («Входящие», «Отправленные», «Спам», «Корзина» и другие). Письма можно читать, искать, скачивать вложения, отвечать, пересылать, удалять и писать новые письма с файлами до 20 МБ.
- Картинки из интернета в письмах по умолчанию скрыты, чтобы отправитель не узнал о прочтении. Их можно показать кнопкой.
- Если письмо от клиента из базы, рядом видно его имя и сделки. В карточке сделки есть блок «Переписка» с письмами этого клиента. Письмо, отправленное клиенту из базы, попадает в историю его сделок.
- Переписку видит только владелец ящика: директор и коллеги чужую почту не видят. Пароли ящиков хранятся в базе в зашифрованном виде. Ключ шифрования лежит в `data/mail.key` или задаётся в `.env` строкой `MAIL_SECRET`.
- Доступ к почте настраивается в правах сотрудника: «Почта → Видеть» открывает раздел, «Почта → Добавлять» разрешает отправлять письма.
- Серверу нужен исходящий доступ к портам 993 (IMAP) и 465 или 587 (SMTP). У большинства хостингов он открыт.

## Как работает доступ сотрудников

- Директор приглашает сотрудника в разделе «Сотрудники». На почту сотрудника приходит письмо со ссылкой: по ней он придумывает пароль, после чего его кабинет становится активным. Если почта не настроена, CRM покажет ссылку, и её можно отправить сотруднику вручную.
- Права настраиваются таблицей: для каждого раздела (дашборд, сделки, этапы сделок, клиенты, задачи, договоры, финансы, база знаний) отдельно отмечается, может ли сотрудник видеть, добавлять, изменять и удалять. Для почты: «Видеть» — читать свою почту в Орбите, «Добавлять» — отправлять письма. «Изменять» в сделках — это вести сделку: двигать по этапам, менять поля, писать комментарии. «Этапы сделок» — настройка столбцов воронки.
- Готовые шаблоны: «Полный доступ», «Менеджер по продажам», «Только ведение сделок», «Наблюдатель». Шаблон заполняет таблицу, после этого любую галочку можно поменять.
- Общие настройки: «Видит суммы и доходность», «Только свои клиенты», «Может приглашать сотрудников». Сотрудник с правом приглашать может выдавать другим только те права, которые есть у него самого, и не может менять свои права.
- Все ограничения проверяет сервер, поэтому обойти их через браузер нельзя.
- После 5 неудачных попыток входа логин блокируется на 15 минут.
- В разделе «Сотрудники» видно, кто сейчас в сети, а у остальных — когда они последний раз были в сети.
